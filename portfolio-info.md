## Experiência Profissional

### DEEPESG — Fullstack Software Engineer

Desenvolvimento e manutenção de uma plataforma SaaS multitenant para gestão ESG. Principais entregas:

- Projetei e construí um módulo GHG de emissões do zero, consolidando 28 tabelas em 5 (emissões, emissões não-Kyoto, fontes de emissão, filtros salvos, traduções), eliminando inconsistências recorrentes de dados.

- Construí um sistema de agendamento de tarefas integrando Google Pub/Sub e Cloud Scheduler, processando ~300 tarefas mensais.
- Refatorei o módulo de gestão de empresas para multitenancy, reduzindo o tempo de criação de empresa de ~1 hora para menos de 5 minutos.
- Desenvolvi export multi-tab XLSX/CSV para dados de emissões, suportando 28 categorias e 40+ filiais.
- Implementei i18n gerenciado via banco de dados com 3 idiomas, eliminando redeploys para atualizações de tradução.
- Migrei 10+ componentes de Vue 2 para Vue 3 e documentei novos componentes no Storybook.
